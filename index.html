About

keyboard_arrow_down
I am sure that 99% of the people reading this have at least heard of AI and machine learning. Behind all the hype though, AI and neural networks are just organized systems of math tuned in a very specific way to do what we want them to do. In this case, I wanted it to classify digits, but it can be used for pretty much any task if you have the data to train it.

Neural networks are somewhat based off the human brain. There are 'neurons' that are connected to others through multiple layers. In a biological brain, neurons fire electrical signals to each other when they detect specific stimuli. With this electronic network, the biological components are replaced with numbers, matrices, and functions.

When you draw on the canvas, your image is transformed into individual pixel values. These values act as the initial input, traveling in a one-way direction through the hidden layers. Below, you can see the structure of this network. Draw on the canvas above to see the results change.

Structure

1. Preprocessing

Preprocessing is an often overlooked step of the process since, frankly, it's not very interesting. But it can often greatly improve the accuracy of the network. In this case, the digit is centered on the canvas, scaled and then flattened into one long array.

2. Input

The input layer is the first of the neural network. Each neuron takes on the normalized value of its corresponding pixel. Since the images are 28 x 28, there are 784 total input neurons

3. Hidden layers

The pixel signals travel forward through the hidden layer(s). Here, thousands of interconnected mathematical weights and biases detect abstract patterns like loops, straight lines, and sharp edges. These can be combined to recognize the digit.

4. Output

Finally, the data reaches the 10 nodes of the output layer (one for each digit from 0 to 9). Because the raw outputs (logits) are unscaled, we apply a softmax activation function to turn them into a probability distribution that totals 100%.

Weights and Biases

In neural networks, weights are just values that determine how strongly one neuron influences the next. For example, a large positive weight would strengthen a signal wheras one close to zero would suppress it. Biases are similar, but instead of multipling them by the neuron value, you add them. The whole point of training a neural network is adjusting millions of these tiny numbers so that useful patterns can be detected.

I'm skipping over a ton of math here, but here's the basic idea: to get the value for a neuron, multiply by the weights from the previous layer and add the bias for that specific neuron.
If you click on one of the hidden layer neurons above (second layer, light blue), you can actually view the weights in a 28 x 28 grid. Pixels with higher weights are the most important to that neuron.

Training

When a network is first initialized, all its weights and biases are completely random. So it basically guesses at everything you give it. To make the AI actually smart, thousands of labeled images are fed into the network to correct its mistakes

This correction process relies on a Loss Function, which calculates mathematically 'how wrong' the network's guess was. If the network is highly confident in the wrong number, the loss is high. If it correctly identifies the digit, the loss is low. Our goal is to get this loss as close to zero as possible.

The green line shows training loss dropping over time as the network trains. The orange line shows validation loss (how good the network does on new data). If the orange line is high, while the green is low, it means that the network is overfitted: it basically memorizes the training data but can't generalize to new inputs. I tried to keep them as close to one another as possible.
To actually adjust the weights and biases (which is how the network 'guesses' something), we use an algorithm called backpropagation. Working backward from the output layer to the input layer, the algorithm calculates how much each individual weight and bias contributed to the final error. It uses calculus (specifically, the chain rule, if anyone is curious) to find the derivative of the loss with respect to every single parameter.

If you're not familiar with derivatives, think of it as calculating How much you need to change the weight/bias in order to lower the cost.

Once these gradients are calculated, an optimization algorithm called Gradient Descent nudges every weight and bias in the direction that reduces the error (cost). By repeating this process millions of times over thousands of images, the network slowly adjusts its weights in a way that makes it able to detect and classify digits.

Hyperparameters

It may seem like you could simply boot up a neural network, give it data, and have it be >90% accurate easily. Yeah, no. Unless you get lucky, most of the time you have to tweak things called Hyperparameters. These are numbers and booleans that change how the network learns slightly, causing different effects. Here are some common ones that I used:

Current Config

Batch Size: 64
Learning Rate: 0.01
Dropout: 20%
Activation: ReLU
  • Epochs: The number of epochs is how many times the network loops over the data. Normally, the more epochs the better the network. However, at some point, the network can become Overfitted, meaning that it is so tuned to the specific training data, it doesn't do well with new inputs
  • Batch Size: This is the number of training examples the network looks at before it calculates the error and updates its weights. Instead of feeding all 60,000 images into the network at once (which takes too much memory) or doing it one by one (which takes too much time), we split them into 'batches' (like 32 or 64 images). It balances speed and training stability.
  • Learning Rate: Adjusts how much the network updates its weights and biases after seeing a mistake. If it's too low, the network is stable but can take forever to learn. If it's too high, the network makes massive adjustments, causing the loss to jump wildly up and down without ever finding the right balance.
  • Dropout Rate: You know how I mentioned overfitting? Dropout can help with that. During training, dropout randomly disables a certain percentage of neurons in a layer. This forces the remaining neurons to step up, preventing the network from relying too heavily on any single path.
  • Activation Function: These are mathematical formulas applied to a neuron's output to introduce non-linearity. Without them, a neural network is just a giant linear equation that can only solve incredibly simple problems. Swapping functions--like using ReLU (which turns negative numbers to zero) versus Sigmoid--can completely change how fast and effectively a network trains.
