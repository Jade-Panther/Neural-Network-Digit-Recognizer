# An Interactive Neural Network Digit Classifier
#### By Quantum Cat, July 2026

Should be around 95% accurate.

## Digits_It_Confuses:
- 4 with a top closed looks like 9 depending on how curved you make it.
- 0 with a cross doesn't work most of the time. I think this is because there are hardly any cross 0s in the dataset. So just..don't draw it like that
- Depending how you draw the 1 it can sometimes mistake as a 7 or 2
- 3s can be a little difficult
